Réseaux / Cisco Packet Tracer Intermédiaire 40 minutes

Interconnexion de Sous-Réseaux et Routage Statique

Apprenez à concevoir une topologie multi-routeurs sous Cisco Packet Tracer et à configurer le routage statique pour assurer la communication inter-LAN.

Avant de commencer (Prérequis)

  • Logiciel Cisco Packet Tracer installé et opérationnel
  • Notions de base sur le découpage en sous-réseaux (VLSM / CIDR)
  • Compréhension du rôle de la passerelle par défaut (default gateway)

Ce que vous allez apprendre

  • Placer et relier des équipements actifs (routeurs, switchs, PC)
  • Configurer les interfaces réseau des routeurs Cisco (IOS)
  • Mettre en place des routes statiques pour interconnecter des réseaux distants
  • Tester la connectivité de bout en bout avec les outils de diagnostic (ping, traceroute)

1. Introduction au Routage Inter-LAN

Dans une architecture réseau complexe, les équipements situés sur des sous-réseaux différents ne peuvent pas communiquer directement de couche 2 en couche 2. Ils ont impérativement besoin d'un routeur et de tables de routage correctement configurées pour acheminer les paquets de données d'un réseau à un autre.

2. Configuration CLI du Routeur Cisco

Étudiez et appliquez la séquence de commandes IOS ci-dessous sur votre routeur principal pour configurer les interfaces et activer le routage statique.

text / router-config.ios 
enable
configure terminal

# Configuration de l'interface LAN
interface GigabitEthernet0/0
 ip address 192.168.1.1 255.255.255.0
 no shutdown
exit

# Configuration de l'interface WAN / Liaison inter-routeur
interface Serial0/0/0
 ip address 10.0.0.1 255.255.255.252
 clock rate 64000
 no shutdown
exit

# Ajout d'une route statique vers le réseau distant
ip route 192.168.2.0 255.255.255.0 10.0.0.2

write memory

À retenir

  • Ne pas oublier la commande no shutdown pour activer administrativement une interface physique.
  • Sur une liaison série (Serial), l'un des routeurs doit obligatoirement fournir l'horloge via la commande clock rate.
  • La route statique nécessite de spécifier le réseau cible, son masque et l'adresse IP du saut suivant (next-hop).

3. Passez à l'action

Défi Pratique sous Packet Tracer

Réalisez l'exercice suivant directement dans votre espace de travail Packet Tracer :

  • Construisez une topologie comportant 2 routeurs, 2 switchs et 4 PC répartis sur deux sous-réseaux distincts.
  • Attribuez les adresses IP adéquates aux stations de travail en n'oubliant pas de configurer leur passerelle par défaut.
  • Mettez en place le routage statique bidirectionnel pour permettre à un PC du réseau A de joindre un PC du réseau B avec succès.
