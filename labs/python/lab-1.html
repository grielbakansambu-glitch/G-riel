Monitoring et Automatisation Système avec Python

Découvrez comment remplacer vos scripts Bash complexes par Python pour superviser l'état de santé de vos serveurs de manière plus robuste et lisible.

Avant de commencer (Prérequis)

  • Python 3.x installé sur votre environnement (Linux de préférence)
  • Connaissance basique de la syntaxe Python (variables, fonctions, conditions)
  • Compréhension de l'arborescence des systèmes de fichiers

Ce que vous allez apprendre

  • Interagir avec le système d'exploitation via les modules natifs (os, shutil)
  • Créer un système de journalisation (logging) professionnel
  • Surveiller l'espace disque d'une partition et générer des alertes
  • Gérer les exceptions pour éviter les plantages de vos scripts

1. Pourquoi Python en Administration Système ?

Bien que Bash soit incontournable, Python devient extrêmement puissant lorsque les scripts grandissent. Il offre une gestion d'erreurs avancée (try/except), des structures de données complexes (dictionnaires, listes) et une bibliothèque standard riche qui évite d'enchaîner des commandes avec des "pipes" (|) fragiles.

2. Le Script de Monitoring d'Espace Disque

Ce script vérifie l'espace disponible sur une partition spécifique et enregistre le résultat dans un fichier journal. Si le seuil d'alerte est dépassé, une alerte est levée.

python / disk_monitor.py 
#!/usr/bin/env python3
import shutil
import logging
import sys

# Configuration du fichier de log
logging.basicConfig(
    filename='/var/log/disk_monitor.log',
    level=logging.INFO,
    format='%(asctime)s - %(levelname)s - %(message)s'
)

def check_disk_usage(disk, threshold):
    """Vérifie l'utilisation du disque et compare avec un seuil en pourcentage."""
    try:
        stat = shutil.disk_usage(disk)
        percent_used = (stat.used / stat.total) * 100
        
        if percent_used > threshold:
            msg = f"ALERTE CRITIQUE : L'utilisation de {disk} a atteint {percent_used:.1f}% !"
            print(msg)
            logging.error(msg)
            return False
            
        msg = f"OK : L'utilisation de {disk} est stable à {percent_used:.1f}%."
        print(msg)
        logging.info(msg)
        return True
        
    except FileNotFoundError:
        error_msg = f"Erreur : Le chemin {disk} est introuvable."
        print(error_msg)
        logging.critical(error_msg)
        sys.exit(1)

if __name__ == "__main__":
    print("[*] Démarrage de l'analyse du système...")
    # Vérifie la partition racine (/) avec un seuil d'alerte à 80%
    check_disk_usage("/", 80.0)

À retenir

  • L'utilisation du shebang #!/usr/bin/env python3 permet de rendre le script exécutable directement depuis le terminal.
  • Le module logging est préférable à de simples print() car il permet de garder un historique avec horodatage, indispensable pour le débogage.
  • Le bloc try/except empêche le script de planter brutalement si le dossier cible n'existe pas.

3. Passez à l'action

Défi Pratique

Faites évoluer ce script pour qu'il réponde aux besoins d'une infrastructure plus complexe :

  • Modifiez la fonction pour qu'elle accepte une liste de partitions (ex: ["/", "/var", "/home"]) et les vérifie toutes avec une boucle for.
  • Utilisez le module subprocess pour récupérer la charge CPU actuelle (via la commande uptime ou top) et l'ajouter aux logs.
  • Planifiez l'exécution de ce script python toutes les 5 minutes en utilisant le crontab de votre système Linux.
